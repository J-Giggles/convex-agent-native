# Security policy

Please report suspected vulnerabilities privately through the repository host's security-advisory feature once the public repository exists. Do not include live credentials, personal data, raw messages, financial identifiers, or production payloads in a report.

Supported releases and response targets will be published before the first release. Until then, the source is pre-release and has no production support commitment.

The package treats authorization, scope derivation, approval checks, idempotency, and audit projection as fail-closed boundaries. Hosts remain responsible for deployment authentication and transport security.
