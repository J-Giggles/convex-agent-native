# Support

This is a community-maintained pre-1.0 project. Support is best effort and there is no production service-level agreement.

## Where to ask

- Use [GitHub Discussions](https://github.com/J-Giggles/convex-agent-native/discussions) for installation help, architecture questions, ideas, and examples.
- Use [GitHub Issues](https://github.com/J-Giggles/convex-agent-native/issues) for reproducible bugs and accepted, bounded feature work.
- Use a [private security advisory](https://github.com/J-Giggles/convex-agent-native/security/advisories/new) for vulnerabilities or reports containing sensitive security detail.

Include the package version, Convex version, Node.js version, minimal reproduction, expected result, and actual result. Remove secrets, deployment keys, personal data, model prompts containing private data, and production payloads.

Builder.io maintains the original Agent-Native project. Questions about its official implementation belong in [BuilderIO/agent-native](https://github.com/BuilderIO/agent-native); questions about this independent Convex compatibility package belong here.
